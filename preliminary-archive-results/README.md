# Preliminary Mathematical Object Origin Archives

This directory contains 114 preliminary mathematical-object origin archives generated and verified with the Moonshine archive runner.

The collection combines three runs:

| Run | Archives |
| --- | ---: |
| `collected-concepts-v1` | 14 |
| `mathematical-context-test-v4` | 38 |
| `mathematical-context-test-v5` | 62 |
| **Total** | **114** |

The archive files are arranged alphabetically by mathematical object and numbered consecutively. Each archive records:

- a precise mathematical description;
- the mathematical context and formation of the object;
- the essential role the object played in addressing its motivating problem;
- notes and sources where applicable.

These documents are initial research outputs rather than a final reference work. They passed the runner's mathematical, content-accuracy, and format checks, but individual claims and source interpretations may still benefit from independent expert review.
